# 🧰 ACM / OI 常用板子（模板集）

> 按知识点分类整理的 C++17 算法模板，随刷题仓库一起维护。
> **每个 `.cpp` 都是可独立编译的完整程序**：上半部分是可用模板，下半部分 `main()` 是一个小的演示，可运行验证效果。拿题时把需要的函数/类片段复制进你的解答即可。

## 使用姿势

- **查某个算法** → 到对应分类文件夹找对应板子文件。
- **复制进题解** → 只复制模板部分（函数/类/全局常量和 typedef），不要复制演示 `main()`。
- **本地验证** → 直接编译运行该文件，看演示输出是否正确：
  ```bash
  g++ -std=c++17 -O2 "数据结构/线段树.cpp" -o main && ./main
  ```
- 想修改/扩充 → 每个文件夹直接加新 `.cpp` 即可。生成器和 CI 会自动跳过（`板子/` 不会进 README 题解列表）。
