## 一、过题策略(先记牢，比刷题还重要)

- 开场先把**所有题扫一遍**，按难度/可得分排序；
- **签到 + 简单题无论多简单都先拿满**——这是分母分，最稳；
- 再攻中等题：**每题限时约 40 分钟**，超时就先跳过，别死磕；
- 难题放最后，能写**暴力/部分分**就先写（数据范围小就暴力，别空着）；
- 先看**数据范围** → 判断算法 → 再动手，比直接写码更省时间。

## 二、3 周冲刺安排

### 第 1 周（→ 9.7）：摸底 + 补板子
- 做 1 场 3 小时**真题模拟**，摸清自己能拿多少分；
- 对照下方考点清单，把缺的板子补进 `洛谷/板子/` 对应文件夹；
- 每天 1 道中等题 + 复习 2 个板子。

### 第 2 周（→ 9.14）：强化弱项
- **每周 2 场限时模拟**（周六下午 3h + 周三晚 1 场）；
- 集中补**数据结构 / 图论 / 字符串**里最弱的一项；
- 练**快速读入（快读）+ STL 高效用法**，能省大量时间。

### 冲刺周（→ 9.18）：只看不学
- 只看 `洛谷/板子/` 模板 + `ACM学习/` 的 lesson，**不再学新算法**；
- 过一遍易错点（边界、取模、long long、数组开大）；
- **保证睡眠**，别熬夜赶题，心态第一。

### 9.19 预选赛当天
- 提前进系统、备好模板、检查环境；
- 按「签到→简单→中等→难题」顺序打，稳扎稳打。
