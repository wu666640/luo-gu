## 2. 常用 STL / 小技巧

- **快读快写**(`基础/快读快写`)— 大规模输入必备。
- `sort` + 自定义 `cmp`；`priority_queue` 默认大根堆，小根堆用 `greater`。
- `map` / `unordered_map`；`set`；`vector`；`deque`(双端)。
- 位运算：`__builtin_popcount`(二进制1的个数)、`__builtin_ctz`、`__int128`(防溢出)。
- 取模组合：`数学/组合数与逆元`。

## 3. 易错点(考前过一遍)

- **int 溢出 → 用 `long long`**(乘法、求和、2^31 附近)。
- **数组开大一点**(比上限 +5)，越界 = 玄学 WA/RE。
- C++ 负数取模结果是负数 → 手动 `(a%m+m)%m`。
- **0-index vs 1-index** 统一，别混。
- 边界：`n=0/1`、全是相同、空数组、最大/最小。
- **多组数据**：每组开始**清空全局变量 / 重置数组**。
- 二分边界：`l<r` 习惯，注意闭开区间。
- 判断相等用 eps(浮点)。
- 拓扑/判环别忘了**入度处理**。
