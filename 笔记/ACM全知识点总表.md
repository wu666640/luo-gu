## 01 C++ 基础与 STL

- 数组：定长连续存储，下标从 0 开始，越界不报错
- 字符串：`std::string` 支持拼接、比较、查找、切片
- 函数：传值、传引用、默认参数，大容器用 `const &`
- 结构体：自定义类型，配合排序比较器使用
- 指针：`&` 取地址，`*` 取值，后面链表树节点会用到
- 递归：边界条件加自调用，先把“这一层做什么”想清楚
- `vector`：动态数组，`push_back`、`pop_back`、`sort`
- `stack`：后进先出，`push`、`pop`、`top`
- `queue`：先进先出，`push`、`pop`、`front`
- `priority_queue`：默认大顶堆，小顶堆加 `greater<int>`
- `set`：自动去重、有序，`insert`、`count`、`erase`
- `map`：键值对，按键排序，`mp["key"]` 会自动创建
- `string`：`substr`、`find`、`stoi`、`to_string`、`getline`
- `sort`：排序，可自定义比较函数
- `lower_bound`：第一个大于等于目标的位置
- `upper_bound`：第一个大于目标的位置
- `binary_search`：判断目标是否存在
- `reverse`：反转容器或字符串
- `next_permutation`：下一个字典序排列
- 复杂度：`O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n)`
- 输入输出：`cin/cout` 加 `ios::sync_with_stdio(false); cin.tie(nullptr);`，换行用 `'\n'`

## 02 搜索

- DFS：深度优先搜索，递归展开所有可能
- BFS：广度优先搜索，队列逐层扩展，适合最短步数
- 回溯：选择后递归，再撤销选择
- 剪枝：提前排除不可能的分支
- 记忆化搜索：把重复状态存下来，是 DP 的入口
- 双向搜索：从起点和终点同时搜，减少状态数
- 启发式搜索：用估价函数决定先搜哪个状态
- A*：带估价的最短路搜索，`f = g + h`
- 迭代加深：一层一层限制深度
- IDA*：迭代加深加 A* 的估价
- Dancing Links：解决精确覆盖问题
- Alpha-Beta：博弈树剪枝，减少无用的搜索
- 搜索优化：双向、剪枝、记忆化、状态压缩

## 03 动态规划

- DP 基础：最优子结构加无后效性
- 记忆化搜索：递归加数组缓存，最容易上手的 DP
- 01 背包：每件物品选或不选
- 完全背包：每件物品可以选无限次
- 多重背包：每件物品有数量限制
- 分组背包：每组只能选一个
- 线性 DP：LIS、LCS、最大子段和
- 区间 DP：先小区间再大区间，石子合并是代表
- DAG 上的 DP：按拓扑顺序转移
- 树形 DP：自底向上合并子树答案
- 状压 DP：用二进制表示状态集合
- 数位 DP：按位处理，处理“小于等于 n”类问题
- 插头 DP：棋盘连通性问题
- 计数 DP：方案数统计
- 动态 DP：支持修改的树形/矩阵 DP
- 概率 DP：按概率转移，注意逆推
- DP 套 DP：把内层 DP 结果作为外层状态
- 单调队列优化：窗口最值转移
- 单调栈优化：找左右边界转移
- 斜率优化：维护凸壳，处理形如 `dp[i] = max(dp[j] + a[i]*b[j])`
- 四边形不等式优化：满足单调性时压缩决策点
- Slope Trick：处理绝对值类凸函数 DP
- WQS 二分：带限制的凸优化

## 04 字符串

- 字符串基础：`char[]` 和 `std::string`
- 标准库 string：`substr`、`find`、`getline`、转换
- 朴素匹配：暴力比较，O(n*m)
- 字符串哈希：把子串映射成整数，O(1) 判断相等
- Trie：按前缀建树，查单词和前缀
- KMP：前缀函数跳过重复比较，O(n+m)
- Z 函数：每个后缀和原串的最长公共前缀
- Manacher：一次扫描找所有回文子串
- Boyer-Moore：从右往左匹配，实践很快，竞赛少见
- AC 自动机：Trie 加失败指针，多模式串匹配
- 后缀数组 SA：所有后缀排序，配合 height 做 LCP
- 后缀自动机 SAM：保存所有子串的最小自动机
- 广义 SAM：多字符串版本的 SAM
- 后缀树：所有后缀压成的压缩 Trie
- 后缀平衡树：动态后缀排序
- 回文树 PAM：统计所有回文子串和出现次数
- 序列自动机：预处理好“下一个字符位置”，做子序列问题
- 最小表示法：找循环移位中字典序最小的串
- Lyndon 分解：分解成字典序不增的 Lyndon 词
- Main-Lorentz：找字符串里所有重复片段

- 二叉堆：优先队列实现，插入和取最值 O(log n)
- 配对堆：支持合并的堆
- 左偏树：可合并堆
- 分块：把数组分成块，平衡复杂度
- 块状数组：分块思想的简单实现
- 块状链表：分块加链表
- 树分块：树上分块处理
- Sqrt Tree：预处理加速 RMQ
- 单调栈：维护单调性，找最近更大更小
- 单调队列：滑动窗口最值
- ST 表：静态区间最值，O(1) 查询
- 树状数组：单点改、区间查，也做逆序对
- 线段树：区间修改查询，支持懒标记
- 线段树合并分裂：按值域合并
- 李超线段树：维护直线求最值
- 猫树：静态区间操作优化
- Segment Tree Beats：区间最值操作
- 划分树：求区间第 k 小
- BST：二叉搜索树
- Treap：随机优先级平衡树
- Splay：伸展树，支持区间操作
- WBLT：重量平衡树
- 替罪羊树：暴力重建平衡树
- 笛卡尔树：按值建树，区间最值问题
- Size Balanced Tree：SBT
- AVL 树：严格平衡
- 红黑树：标准库 `map/set` 常用实现
- 跳表：概率型有序结构
- 可持久化线段树：主席树，查历史版本和区间第 k 小
- 可持久化平衡树：可回退版本
- 可持久化字典树：异或最大值类问题
- 线段树套线段树：二维区间问题
- 平衡树套线段树：区间内动态查询
- 树状数组套权值线段树：动态第 k 小
- K-D Tree：多维空间搜索
- Link Cut Tree：动态树，支持换根、连边、删边
- Euler Tour Tree：用括号序维护动态树
- 析合树：排列连续区间问题
- Huffman 树：合并果子、最优前缀编码

## 06 图论

- 图论概念：点、边、度、路径、连通、环
- 图的存储：邻接矩阵、邻接表、链式前向星
- 图的 DFS：深搜遍历、判环、求连通块
- 图的 BFS：广搜遍历、无权图最短路
- 树基础：父亲、深度、子树大小、DFS 序
- 树的直径：树上最远两点距离
- 树的中心：到所有点最远距离最小的点
- 树的重心：删掉后最大子树最小
- LCA：最近公共祖先，倍增或树剖
- 树链剖分：把树变成若干链，配线段树
- 树上启发式合并：DSU on tree，统计子树信息
- 虚树：只保留关键点和 LCA
- 树分治：点分治解决路径统计
- 树哈希：给树判同构
- DAG：有向无环图
- 拓扑排序：按依赖顺序处理
- Dijkstra：非负权最短路
- Floyd：全源最短路，O(n^3)
- Bellman-Ford：可判负环
- SPFA：Bellman-Ford 队列优化
- 差分约束：最短路建模不等式
- k 短路：A* 或可持久化堆
- 同余最短路：用最短路解同余问题
- Kruskal：最小生成树，排序加并查集
- Prim：最小生成树，点扩展
- 最小树形图：有向图最小生成树
- 斯坦纳树：指定点集连通最小代价
- 强连通分量 SCC：互相可达的极大点集，缩点
- 双连通分量 BCC：点双、边双
- 割点和桥：删掉后图不连通
- 圆方树：点双转成树
- 2-SAT：布尔约束可满足性
- 欧拉图：一笔画问题
- 哈密顿图：经过所有点一次
- 二分图：分成两组，边只在组间
- 平面图：可以无交叉画在平面
- 弦图：每个环都有弦
- 图的着色：最少颜色
- 最大流：从源到汇最多流量
- 最小割：割掉最少容量使图不连通
- 费用流：带费用的最大流
- 上下界网络流：边有流量上下界
- Stoer-Wagner：无向图全局最小割
- 二分图最大匹配：匈牙利算法
- 二分图最大权匹配：KM 算法
- 一般图最大匹配：带花树
- 稳定匹配：Gale-Shapley
- Prüfer 序列：树与序列互转，计数生成树
- 矩阵树定理：求生成树个数
- LGV 引理：不相交路径计数
- 支配树：必经点问题
