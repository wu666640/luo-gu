# 🕸️ 图论:从"不会建图"到"系统化建模"

> 你的痛点很典型：**算法都会(最短路/DFS/BFS)，但一看到题解里五花八门的建图就懵。**
> 真相是：建图只有**三板斧**——①图上是什么(建模)②怎么存(存图)③算啥(算法)。
> 题解看起来千差万别，主要是**第①点**在变。把下面这套固定套路记住，建图就不再玄学。

---

## 一、为什么每次建图"都不一样"？—— 只有 3 个变量

| 变量 | 变化点 | 决定 |
|---|---|---|
| **① 图上是什么** | 顶点/边/边权怎么定义(最常变) | 这道题是"图论哪一类" |
| **② 怎么存** | 邻接矩阵/邻接表/边集/链式前向星 | 代码写法 |
| **③ 要算什么** | 最短路/连通块/生成树/判环/拓扑… | 用哪个算法 |

题解里建图不同，**90% 是①在变(用了不同建模技巧)**，不是玄学。你只要抓住"顶点/边/边权/要求"四个词，就能把任何建图归位。

---

## 二、建模四问（拿到任何图论题，先问这 4 句）

> 把这 4 句当固定面具，每次套一遍，答案自然浮出来。

1. **谁是顶点？** —— 图里每个点代表什么对象/状态？
2. **什么时候连边？** —— 两个点之间为什么相连？有向还是无向？
3. **边权是什么？** —— 代价 / 距离 / 容量 / 依赖关系？
4. **要求什么答案？** —— 最短距离？连通块数？最小生成树？能否到达？判环？最大流？

**例子·网格最短路**：顶点=每个格子；边=上下左右走到相邻格子；边权=移动代价；答案=起点到终点最短路 → BFS/Dijkstra。

## 三、存图怎么选（3 种，别纠结）

| 方式 | 写法 | 什么时候用 |
|---|---|---|
| **邻接表**(首选) | `vector<int> g[N];` 带权 `vector<pair<int,int>> g[N];` | **默认就用它**，稀疏图最常用 |
| **邻接矩阵** | `int g[N][N];` | 点数小(≤ ~1000)、要 O(1) 查边 |
| **边集** | `struct Edge{int u,v,w;}; vector<Edge>` | Kruskal / Bellman-Ford 要遍历所有边 |
| 链式前向星 | 数组版邻接表 | 卡常数/超大图才用，新手不必 |

> 一句话：**默认 vector 邻接表**，用熟了再考虑别的。别把时间花在存图炫技上。

**邻接表带权模板：**
```cpp
struct Edge{int to, w;};
vector<Edge> g[N];
// 加一条 u->v 权 w 的有向边
g[u].push_back({v, w});
// 无向边就加两条
g[v].push_back({u, w});
```

## 四、8 种建图技巧（这就是你看到的"不一样"）

> 每个技巧给「什么时候用 + 图长啥样」。你以后看题解，先在脑子里匹配是哪一招。

### 1️⃣ 直接建图
- **用**：题目本身就是图(对象=点，关系=边)。
- **图**：直接 `g[u].push_back(v)`。最简单的起点。

### 2️⃣ 网格图(坐标→点)
- **用**：棋盘/网格/迷宫类。
- **图**：把 `(x,y)` 映射到一维编号 `id = x*m + y`；上下左右 4 邻居连边，可带移动代价。
- **典型**：P1443 马的遍历（方向是 8 个马步）、迷宫最短路。

### 3️⃣ 拆点 / 状态图
- **用**：**"从 u 走到 v 的代价还取决于当前状态"**(体力、钥匙、层数、还能免费几次)。
- **图**：把一个点拆成多个状态点，编号 = `id(u, state)`。即 **分层图**。
- **典型**：P4568 飞行路线（免费 k 次）、P1073 最优贸易（买/卖两状态）。

### 4️⃣ 虚拟源点 / 超级源汇
- **用**：**多起点求最短路**，或想统一处理。
- **图**：加一个 0 号点，向所有起点连 0 权边 → 变成单源最短路。
- **典型**：多起点 BFS（多个火源一起扩散）问题。

### 5️⃣ 反向建图
- **用**：**求"其他所有点到 X 的最短路"**，或求可达性/方案数。
- **图**：把边反向，从 X 跑一遍即可（省 N 次最短路）。
- **典型**：P1629 邮递员送信、P2296 寻找道路。

### 6️⃣ 缩点（Tarjan 强连通分量）
- **用**：图里有环，环内互相可达 → 先把每个 SCC **缩成一个点**，变成 DAG，再拓扑 DP/最长路。
- **典型**：P1262 间谍网络、P2746 校园网、P2002 消息扩散。

### 7️⃣ 0-1 BFS（边权只有 0/1）
- **用**：边权只有 0 和 1 的最短路。
- **图**：0 权边放队首，1 权边放队尾，用 `deque` 代替 Dijkstra（O(V+E)）。
- **典型**：P4554 小明的游戏。

### 8️⃣ 差分约束（把不等式转最短路）
- **用**：一堆形如 `x_v - x_u ≤ w` 的不等式，求一组解。
- **图**：`u → v` 连权 `w` 的边，跑最短路（或最长路）。
- **典型**：P3275 糖果、P1993 差分约束系统。

> 剩下的**二分图匹配、最大流/最小割、补图**等，属于 1600+ 内容，先放一放。上面 8 招够你打到 1500。

## 五、系统学习顺序（图论主线）

1. **图的概念 + 存图(邻接表) + 遍历**（DFS/BFS）
2. **最短路**：Dijkstra → Floyd → SPFA（负权/判负环）
3. **最小生成树**：Kruskal / Prim
4. **拓扑排序 / 判环 / DAG 上 DP**
5. **连通性**：并查集、Tarjan（强连通/割点/桥）
6. **建模技巧**（上面 8 招）+ 专项练习
7. 网络流 / 二分图（1600+ 再学）

每学一个算法 → 配套刷 5–10 题 → 把板子加进 `洛谷/板子/图论/`。

## 📌 一句话总结

> **建图＝搞清楚「顶点是谁、边怎么连、边权是啥、要算什么」四件事**，先建模再存图再选算法。
> 题解里的"不一样"，翻来覆去就是上面那 8 招。记住它们，你也能写出一眼就能看懂的建图。
